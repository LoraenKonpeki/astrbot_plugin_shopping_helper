# 联盟购物助手

用于 AstrBot 的官方联盟商品搜索插件。首版实现京东联盟搜索；它不会使用 App 逆向接口、登录 Cookie 或网页抓取。

## 功能

- `/购 搜 静音机械键盘`
- LLM 工具 `shopping_search`，供模型按自然语言条件搜索和整理结果
- 统一返回商品名、店铺、价格、优惠、评价数和来源链接
- 内存短缓存，降低联盟接口请求量

## 配置

在 AstrBot 插件管理页填写：

- `jd_app_key` 与 `jd_app_secret`：京东联盟开放平台应用凭证。
- `jd_access_token`：你的应用权限要求时填写。
- `jd_site_id`：预留的联盟推广位；首版搜索返回官方素材链接，尚未生成推广链接。

凭证只应保存到 AstrBot 插件配置或部署环境的 Secret，不能提交进仓库。

## 安装

将本目录放入 AstrBot 的 `data/plugins/`，或在插件市场从 Git 仓库安装。配置完成后插件支持热重载，无需重启 AstrBot。

## 边界

联盟接口的商品覆盖范围、价格、优惠和库存由平台实时决定，回复中的数据仅作查询时快照，购买前以链接页面为准。淘宝联盟、美团等来源尚未启用，避免在没有正式授权的情况下以抓取方式补齐数据。
